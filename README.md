One line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline.

> I checkpointed the deadline to disk, then restored from an older checkpoint where you hadn't set one yet.

`main.ts` (Node stdlib only) copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

Run it with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
